Vice Cover Studio turns any photo and caption into multi-panel GTA-style cover art — Vice City sunset, neon and noir grades — and exports it as a PNG in 1080x1080, 1080x1350 and 1920x1080. Runs offline in a desktop browser from static files; photos never leave the machine.

## Run it

```sh
node serve.ts
```
